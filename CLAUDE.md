# ATV Lampa — суть проекта

Аналог медиацентра **Lampa** для телевизора **LG webOS** с интерфейсом, максимально повторяющим
**приложение Apple TV (tvOS 18/26)**: боковая стеклянная панель, Top Shelf с кадром на весь экран,
полки карточек, фокус с увеличением и параллаксом, экран фильма, звуки навигации.
Данные о фильмах — **TMDB**. Видео — через **TorrServer** (готово), Jellyfin — следующий этап.

## Пользователь
- Новичок в программировании, общается **по-русски**. Код пишет Claude, пользователь проверяет на ТВ.
- Объяснять просто, давать готовые команды, по возможности делать всё самому (Windows, терминал — PowerShell).
- Пользователь смотрит этот ТВ — **не запускать замеры/перезапуски, если на экране его приложение**
  (`com.ott.drm` — его IPTV). Проверить: `npx ares-launch --device tv --running`.

## Телевизор (целевое устройство)
- **LG 49UK6300PLB, webOS 4.4.3** (Chromium 53, слабый 4-ядерный ARM, 843 МБ памяти), IP **192.168.0.11**.
- Рутован, стоит **Homebrew Channel** (Developer Mode не нужен). SSH: `root@192.168.0.11`, ключ `~/.ssh/webos_tv`.
- В утилитах LG устройство называется `tv`. Инструкция по подключению — `TV.md`.
- Код должен работать в **Chromium 53**: без flex `gap`, `inset`, `aspect-ratio`, `isIntersecting` (проверять `intersectionRatio`),
  `backdrop-filter` только через `@supports` (есть с webOS 6). Сборка — только legacy (`@vitejs/plugin-legacy`, `renderModernChunks: false`).

## Стек
Vite + **Preact** + TypeScript, без UI-библиотек. Экран всегда 1920×1080 (на ПК масштабируется).
Ключ TMDB — в `.env.local` (`VITE_TMDB_KEY`, не коммитить, попадает в сборку — не публиковать .ipk). Шаблон — `.env.example`.
TorrServer пользователя: **http://192.168.0.15:8090** (MatriX.141; в `.env.local` как `VITE_TORRSERVER_URL`, меняется в «Настройках»).
Встроенный поиск раздач в нём выключен; парсер (Jackett/jacred) пользователь может указать в «Настройках».
Для проверки в TorrServer лежит тестовая раздача «Sintel» (Blender, CC-BY, хеш 08ada5a7…), TMDB movie:45745 — `?open=movie:45745`.

## Команды
```
npm run dev            # http://localhost:5173 (стрелки, Enter, Esc; ?open=movie:603 — сразу экран фильма)
npm run tv             # сборка → .ipk → установка → запуск на ТВ
npm run tv:screenshot  # снимок экрана ТВ в screenshots/
npm run tv:bench       # автозамер FPS на ТВ по сценариям (таблица на экране + снимок)
```
Профилирование на ТВ (сначала туннель `ssh -i ~/.ssh/webos_tv -N -L 19998:127.0.0.1:9998 root@192.168.0.11`):
`node scripts/trace.mjs` (на что уходит время кадра), `node scripts/layers.mjs ["CSS-опыт"]` (слои отрисовки),
`node scripts/tv-eval.mjs "key(37)"` (выполнить JS / нажать кнопку пульта в приложении),
`node scripts/profile.mjs "<сценарий>"` (профиль JS по функциям; имена видны в сборке `PROFILE=1 npm run tv`, потом вернуть обычную).
Перед замерами проверять `top` на ТВ: оборванные SSH-команды (`grep -r`, `find /`) остаются работать и съедают ядро — так однажды
«пропало» 5–8 fps. Долгие поиски по ФС ТВ запускать с `timeout`.

## Структура `src/`
- `core/focus.ts` — движок фокуса (замена tvOS Focus Engine): стрелки по геометрии, только соседние ряды,
  экраны (`data-screen`), боковая панель (`data-sidebar`: влево с края/«Назад» — открыть, вправо — вернуться),
  прокрутка через transform (`data-scroll-x/-y`, `data-section`), стек «Назад», звуки.
- `core/` — `parallax` (наклон за Magic Remote, отблеск), `lazy` (ленивая загрузка + подгрузка заранее по ходу),
  `quality` (качество обложек), `lite` (облегчённый режим), `sound`, `fps`, `library` (медиатека в localStorage), `bench`.
- `api/tmdb.ts` — запросы, кеш в localStorage, перевод в `Item`; `api/details.ts` — экран фильма и сезоны.
- `data/catalog.ts` — полки вкладок Главная/Фильмы/Сериалы; `data/mock.ts` — данные без ключа TMDB.
- `components/` — `Sidebar`, `Browse` (вкладка с Top Shelf), `Hero`, `ShelfRow`, `Card`, `Artwork`, `Details`,
  `GenreScreen`, `LibraryView`, `SearchView` (экранная клавиатура), `SettingsView`, `TextInput` (ввод адресов),
  `About` (внизу экрана фильма, как в Apple TV: «Описание» — карточки, «Информация / Языки / Создатели» — панели),
  `Sources` (выбор раздачи → файлы/серии), `Player` (плеер tvOS: полоса времени, перемотка, субтитры .srt, панель ↓).
- `api/torrserver.ts` — API TorrServer (запросы text/plain без preflight); `api/releases.ts` — раздачи из TorrServer,
  парсера Jackett и встроенного поиска TorrServer, разбор качества и серий; `core/history.ts` — «Продолжить».
- Стек экранов в `App.tsx`: details → sources → player (фильм из одного файла: плеер заменяет sources).
  Плеер перехватывает кнопки в capture-фазе на window; под плеером остальные экраны `visibility: hidden`.
- `styles/app.css` — все стили (с комментариями «почему так» по замерам), `tokens.css` — токены и стекло.

## Правила производительности (выяснены замерами на этом ТВ — соблюдать!)
- Карточки максимально простые: **не слои** (никаких `will-change`, 3D-transform, даже `perspective()` у обычных карточек),
  минимум позиционированных элементов. Картинка — `background-image` у `.art__bg`, тень — `box-shadow` у рамки.
- **Никаких постоянных анимаций** (Ken Burns уронил прокрутку 56→18 fps; любая бесконечная анимация держит ТВ на 60 кадрах в покое).
  Медленные индикаторы — JS ~5 раз/с без transition.
- Не смешивать лишние полноэкранные слои; не прятать главную под экраном фильма (пересчёт стилей ~1500 элементов).
- Не анимировать `box-shadow`, размытые `text-shadow` на крупном тексте, проявление каждой картинки.
- Тяжёлые эффекты — под `html.lite` (облегчённый режим). Любое изменение интерфейса — проверять `npm run tv:bench`.
- Текущие цифры (эффекты/облегчённый, 25.10.2026): прокрутка 56–60, по главной вниз-вверх 32–37, постеры 44–53,
  открытие фильма 16/37 (было 15/28; JS заглушек 49→27 мс), вниз к сериям 26/38, назад на главную 47/53.
  Разброс между прогонами ±4 fps (зависит от свободной памяти ТВ). Слабое место — открытие фильма с эффектами.
- Заглушки (`artImage`) кешируются по цветам палитры, а не по id. Нижние разделы экрана фильма строятся после
  анимации открытия (450 мс). Большие подложки — сплошным цветом (сплошные тайлы не растеризуются).

## Кнопки пульта
Красная — счётчик FPS, зелёная — облегчённый режим, жёлтая — звуки (на ПК F2/F4/F3). Всё это и «Качество обложек» — в «Настройках».

## Этапы
1. ✅ Прототип главной · 2. ✅ Установка на ТВ · 3. ✅ Экран фильма, дизайн-система · 4. ✅ TMDB, поиск, жанры, медиатека,
   эффекты tvOS, боковая панель, настройки, оптимизация под webOS 4.
5. ✅ **TorrServer + плеер** (выбор раздачи, серии, плеер tvOS, субтитры .srt, «Продолжить»). Проверено в браузере
   и на ТВ (картинка есть — подтвердил пользователь; снимок экрана ТВ слой видео не захватывает).
   Недоделано: выбор аудиодорожек на webOS (нужен luna `com.webos.media`, `audioTracks` в Chromium 53 нет),
   встроенные в mkv субтитры, полка «Продолжить просмотр» на главной, ввод magnet вручную.
6. ⏭ **Jellyfin** (и общий Plugin API источников: `search(item) → Stream[]`, `resolve(stream)`).
7. Полировка: профиль (имя/аватар), ошибки сети, иконка, финальная оптимизация.

## Заметки
- Проект в git (ветка `main`, первый коммит — этапы 1–4). `.env.local` с ключом TMDB не коммитится.
- Мелкие недоделки: «Профиль» в панели без имени; нет страницы актёра; блик карточек отключён на главной (по вкусу пользователя).
