# ATV Lampa

Медиацентр для телевизоров **LG webOS** в стиле интерфейса tvOS: боковая стеклянная панель,
большой кадр Top Shelf, полки карточек с увеличением и наклоном, экран фильма, страницы актёров,
звуки навигации. Фильмы смотрятся через ваш **TorrServer**.

> Неофициальный проект. Не связан с Apple, LG, TMDB или Кинопоиском.
> Приложение не содержит и не раздаёт видео — только показывает каталог и проигрывает то,
> что отдаёт ваш собственный TorrServer.

## Что умеет

- Главная, «Фильмы», «Сериалы», «Детям» — подборки TMDB с описаниями на русском.
- Экран фильма и сериала: сезоны и серии, трейлеры (через YouTube), актёры, похожее, подробности.
- Страница актёра: биография и фильмография.
- Поиск с экранной клавиатурой, жанры, «Медиатека» (кнопка «+»).
- Полка «Продолжить просмотр» на главной и «Следующая серия» с отсчётом в конце серии.
- Выбор раздачи в TorrServer (или через парсер Jackett / Prowlarr / jacred), плеер с перемоткой, выбором озвучки и субтитрами .srt.
- По желанию — оценки и факты **Кинопоиска**.
- Три уровня эффектов для слабых телевизоров; интерфейс 720p или 1080p.

## Что нужно

- Телевизор **LG с webOS 4.0 или новее** (проверено на webOS 4.4, LG 49UK6300).
- **Ключ TMDB** — бесплатный: зарегистрируйтесь на [themoviedb.org](https://www.themoviedb.org/signup),
  откройте *Settings → API*, создайте ключ и скопируйте **API Key** (32 знака).
- Для просмотра — **TorrServer** в вашей домашней сети (на компьютере, приставке или роутере).
- Необязательно: ключ [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech) для оценок Кинопоиска.

## Установка

Скачайте один из файлов [последнего выпуска](https://github.com/ilovedukk-sys/atv-lampa/releases/latest):

| Файл | Для кого |
|---|---|
| `atv-lampa_<версия>_720p.ipk` | **Рекомендуется.** webOS 4–5 и любые не самые быстрые ТВ: заметно плавнее |
| `atv-lampa_<версия>_1080p.ipk` | Быстрые ТВ (webOS 6+): текст чётче |

Установить `.ipk` на телевизор проще всего программой
[webOS Dev Manager](https://github.com/webosbrew/dev-manager-desktop) (Windows, macOS, Linux):

1. На телевизоре нужен **Homebrew Channel** (root) или **Developer Mode** (аккаунт LG для разработчиков).
2. В webOS Dev Manager добавьте телевизор (он сам подскажет, как).
3. Вкладка *Apps* → *Install* → выберите скачанный `.ipk`.

Из командной строки то же самое: `npx ares-install --device tv atv-lampa_1.0.1_720p.ipk`.

> В Developer Mode приложение работает, пока активен режим разработчика (около 50 часов,
> продлевается кнопкой *Extend*). С Homebrew Channel ограничений нет.

Целостность файлов можно проверить по `SHA256SUMS.txt`.

## Первый запуск

1. Приложение откроет **«Настройки»** — выберите *Ключ TMDB*, введите ключ и нажмите *Готово*.
   Ключ проверяется, приложение перезапустится уже с настоящими фильмами.
2. *TorrServer* — адрес вашего сервера, например `192.168.1.10:8090`.
3. По желанию: *Парсер раздач* и *Кинопоиск*.

Все ключи и адреса хранятся только на вашем телевизоре.

## Управление

- Стрелки, «ОК», «Назад» — как обычно; влево с края экрана (или «Назад») — боковая панель.
- Magic Remote: наведение выбирает карточку, движение по ней — наклон, колёсико листает полки.
- Цветные кнопки: красная — счётчик FPS, зелёная — уровень эффектов, жёлтая — звуки.

Если интерфейс подтормаживает — *Настройки → Эффекты: Облегчённый* (или *Минимальный*).

## Для разработчиков

```bash
npm install
npm run dev        # http://localhost:5173 — стрелки, Enter, Esc
npm run tv         # собрать и поставить на свой ТВ (подготовка — TV.md)
npm run release    # файлы выпуска в release/ — без ваших ключей
```

Для разработки ключ TMDB можно положить в `.env.local` (шаблон — `.env.example`).
`npm run release` собирает без него и останавливается, если в сборку попало что-то из `.env.local`.

Стек: Vite, Preact, TypeScript; сборка под Chromium 53 (webOS 4). Устройство кода, правила
производительности и замеры — в `CLAUDE.md`, подключение телевизора — в `TV.md`.
