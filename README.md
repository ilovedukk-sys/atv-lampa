# Apple TV Lampa

Медиацентр для LG webOS 4–6 с интерфейсом в стиле Apple TV (tvOS).

## Запуск на компьютере

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

- Стрелки — как на пульте, Enter — «ОК», Esc / Backspace — «Назад»
- Влево с крайнего элемента (или «Назад») — боковая панель с разделами, вправо — обратно
- Мышь ведёт себя как Magic Remote: наведение = фокус, движение по карточке = наклон, колёсико листает полки

## Сборка для телевизора

```bash
npm run build
```

Готовое приложение — в папке `dist/`.

## Телевизор

Первичная настройка — в [TV.md](TV.md). После неё:

```bash
npm run tv             # собрать, упаковать, установить и запустить на ТВ
npm run tv:bench       # замер плавности на ТВ (таблица на экране + снимок в screenshots/)
npm run tv:screenshot  # снимок экрана ТВ
npm run tv:inspect     # DevTools приложения на ТВ
```

Профилирование на ТВ (нужен туннель `ssh -i ~/.ssh/webos_tv -N -L 19998:127.0.0.1:9998 root@<IP ТВ>`):
`node scripts/trace.mjs` — на что уходит время кадра, `node scripts/layers.mjs` — слои отрисовки,
`node scripts/tv-eval.mjs "key(37)"` — нажать кнопку пульта в приложении.

Отладка: `?open=c1` в адресе (или `ares-launch ... -p '{"open":"c1"}'`) сразу открывает экран фильма.
Кнопки пульта (в скобках — на компьютере):
- красная (F2) — счётчик FPS;
- зелёная (F4) — облегчённый режим без тяжёлых эффектов (быстрее на слабых ТВ);
- жёлтая (F3) — звуки навигации вкл/выкл.

## Структура

```
src/
  core/focus.ts      движок фокуса: стрелки, Enter, «Назад», экраны, курсор, прокрутка
  core/parallax.ts   наклон карточки и блик
  core/library.ts    медиатека (кнопка «+»)
  core/bench.ts      автоматический замер плавности
  components/        боковая панель, Top Shelf, полки, карточки, кнопки, экран фильма, настройки
  data/mock.ts       временные данные (на этапе 4 заменим на TMDB)
  data/details.ts    подробности фильма/сериала (тоже временные)
  styles/            токены дизайна и стили
```
